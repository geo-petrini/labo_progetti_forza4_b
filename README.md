# Forza 4

Forza 4 per due giocatori, giocabile nel terminale. Sei righe, sette colonne: quattro gettoni in fila vincono.

## Avvio

```bash
python main.py
```

## Regole

1. Alternano i turni i giocatori **X** e **O**.
2. Ad ogni turno si sceglie la colonna da 1 a 7: il gettone cade in basso.
3. Vince chi per primo allinea 4 gettoni (in orizzontale, verticale o diagonale).
4. Se la griglia si riempie senza vincitori, la partita è pari.
